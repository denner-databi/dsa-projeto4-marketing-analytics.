
# DSA - Projeto 4: Marketing DW Analytics 📊

Este projeto consiste em um dashboard de Performance de Marketing Digital desenvolvido no Power BI Desktop. O objetivo principal é consolidar dados de um Data Warehouse de marketing para analisar o comportamento de campanhas digitais, custos por plataforma e o retorno financeiro estratégico.

## 🎨 Engenharia de Cores e Layout
O design foi projetado seguindo as melhores práticas de UI/UX para telas de dados (Data Storytelling):
* **Fundo e Estrutura:** Fundo geral em Cinza-Claro (`#F8F9FA`) com cartões em Branco Puro (`#FFFFFF`) e cantos arredondados, reduzindo a fadiga visual e organizando as seções por blocos de contexto.
* **Cor de Destaque (Accent Color):** Amarelo-Mostarda (`#E5A93B`) aplicado estrategicamente para direcionar os olhos do tomador de decisão diretamente para os indicadores de sucesso (como a Taxa de Conversão por Campanha).
* **Tipografia:** Uso de tons grafite escuro (`#2B2D42`) eliminando o preto puro para garantir uma leitura suave e eixos limpos nos gráficos.

## 🧠 Estrutura Técnica e Métricas Analisadas
* **Visão Geral do Funil:** Monitoramento macro através de indicadores de volume: **Total de Impressões (150 Mi)** e **Total de Cliques (76 Mi)**.
* **Análise de Eficiência Financeira:** Distribuição detalhada do Custo por Plataforma (LinkedIn, TikTok, Instagram, Meta Ads, Google Ads) associado ao comportamento do Custo por Clique (CPC) médio.
* **Indicadores de Performance:** Evolução histórica do **ROI YTD** por ano para medição de eficiência de margem sobre investimento de mídia.
* **Machine Learning Integrado:** Uso do visual nativo de Inteligência Artificial do Power BI (*Principais Influenciadores*) para segmentar e mapear o que de fato causa o aumento ou redução do CPC.

## 🛠️ Competências e Ferramentas Aplicadas
* **Power BI Desktop** (Modelagem de dados, design de interface e storytelling)
* **Linguagem DAX** (Desenvolvimento de medidas analíticas estruturadas e cálculos de inteligência de tempo para análise financeira)
* **JSON** (Customização avançada e importação de temas corporativos personalizados)
